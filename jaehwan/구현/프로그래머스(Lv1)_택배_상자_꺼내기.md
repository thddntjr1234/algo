# 택배 상자 꺼내기
 - 정답률 : 38% (11,025명)
 - 난이도 : Lv.1
 - 유형 : 구현 / 위치 계산
 - [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/389478 "프로그래머스 택배 상자 꺼내기")
### 제출 코드
```java
class Solution {
    public int solution(int n, int w, int num) {
        // 목표 상자의 행, 열
        int targetY = (num + w - 1) / w;
        int targetX = (num - 1) % w + 1;
        
        // 마지막 상자의 행, 열
        int maxY = (n + w - 1) / w;
        int maxX = (n - 1) % w + 1;
        
        // 목표 상자의 행이 짝수일경우 열 위치 반전
        if(targetY % 2 == 0) targetX = w - targetX + 1;
        
        // 마지막 열 상자 미포함
        int result = maxY - targetY;

        if(maxY % 2 == 0) {
            maxX = w - maxX + 1; // 열 위치 반전
            if(targetX >= maxX) result++; // 마지막 열의 상자를 포함
        } else { // 열 위치 반전 없이 수행
            if(targetX <= maxX) result++;
        }
        
        return result;
        
    }
}
```


### 풀이 방향
- 상자 번호를 기준으로 목표 상자의 행과 열 계산.
- 짝수 행은 적재 방향이 반대이므로 열 위치 보정.
- 전체 층 수와 마지막 상자의 열 위치 계산.
- 목표 상자 위에 존재할 수 있는 층 수 계산.
- 마지막 층이 목표 열까지 채워졌다면 상자 개수 보정.

### 후기
- 처음에는 2차원 배열을 사용해 직접 쌓는 방식도 고려했지만, 필요한 값은 꺼내야 하는 ***상자의 개수**뿐이므로 좌표 계산 방식으로 접근했다.
- 구현 방향은 빠르게 잡았지만, 상자 번호를 행과 열로 변환하는 과정에서 ``0-based``와 ``1-based`` 기준이 섞여 인덱스 보정이 까다로웠다.
- 특히 올림 나눗셈과 나머지 연산을 사용해 행/열을 계산할 때 경계값을 맞추는 부분에서 고생좀 했다.
- 최대한 가독성 좋고 성능 좋은 코드를 짜고자 노력하는데, 그 과정에서 코드를 처음부터 다시 짜야하는 상황이 종종 생기기도 한다.
